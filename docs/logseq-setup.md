# Open the AI knowledge corpus in Logseq

The packaged graph lives in this repository at **[`docs/logseq-ai-knowledge/`](logseq-ai-knowledge/)**.

## Steps

1. Clone or open a checkout of this repo (`go-agentic`).
2. Launch Logseq → **File → Open a local graph**.
3. Choose the folder `docs/logseq-ai-knowledge` (the one that contains `pages/` and `logseq/`).
4. Open **[[Contents]]** for start-here concepts, the 10 clusters, and links into IBM / Sequoia / Extra corpora.

Full open instructions and layout notes: [`logseq-ai-knowledge/README.md`](logseq-ai-knowledge/README.md).

This build has **178** pages under `pages/`.
