# AI knowledge by theme

Long-form essays that **intersect** IBM, Sequoia, and Extra (OpenAI, DeepMind, Hugging Face, AWS) articles by idea—not by publisher silo.

**Corpus start-here:** [`../README.md`](../README.md).  
**Landscape / orientation** (timeline, players, policy, agent benchmarks): also in the graph/HTML/Logseq surfaces — start at [`../gap-fill-ai-knowledge/`](../gap-fill-ai-knowledge/). Theme essays below cross-link relevant orientation packs.

## Easiest: open in a browser

Double-click **[`themes.html`](themes.html)** (or Chrome/Safari → File → Open File).  
Left sidebar jumps between essays; search filters titles. No Logseq or Google Docs setup.

Corpus-organized companion (baseline + gap-fill): [`../ai-knowledge-articles-readable/articles.html`](../ai-knowledge-articles-readable/articles.html).

## Thematic vs corpus folders

| Layout | Path | Best for |
|--------|------|----------|
| **By theme** (this folder) | `docs/ai-knowledge-by-theme/` | Reading ideas across sources in one sitting |
| **Readable HTML + index** | `docs/ai-knowledge-articles-readable/` | Searchable baseline reader (store name; repo may say `ai-knowledge-articles`) |
| **By corpus Markdown** | `docs/{ibm,sequoia,extra}-ai-knowledge/` | Looking up a specific source article |
| **Gap-fill / landscape** | `docs/gap-fill-ai-knowledge/` | Timeline, players, policy, benchmarks + new sources |
| **Logseq graph** | `docs/logseq-ai-knowledge/` | Linked browsing in Logseq |

Themes deliberately cross silos: definitions first, then how IBM’s operational framing meets Sequoia’s market framing and Extra/lab posts.
