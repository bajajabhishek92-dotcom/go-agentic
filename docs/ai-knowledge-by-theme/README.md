# AI knowledge by theme

Long-form essays that **intersect** IBM, Sequoia, and Extra (OpenAI, DeepMind, Hugging Face, AWS) articles by idea—not by publisher silo.

## Easiest: open in a browser

Double-click **[`themes.html`](themes.html)** (or Chrome/Safari → File → Open File).  
Left sidebar jumps between essays; search filters titles. No Logseq or Google Docs setup.

Corpus-organized companion (86 individual articles): [`../ai-knowledge-articles/articles.html`](../ai-knowledge-articles/articles.html).

## Thematic vs corpus folders

| Layout | Path | Best for |
|--------|------|----------|
| **By theme** (this folder) | `docs/ai-knowledge-by-theme/` | Reading ideas across sources in one sitting |
| **By corpus** | `docs/ai-knowledge-articles/{ibm,sequoia,extra}/` | Looking up a specific source article |
| **Logseq graph** | `docs/logseq-ai-knowledge/` | Linked browsing in Logseq |

Themes deliberately cross silos: definitions first, then how IBM’s operational framing meets Sequoia’s market framing and Extra/lab posts.
